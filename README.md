# Análise de E-commerce Brasileiro — Olist

## 📋 Descrição
Este projeto analisou dados públicos sobre o e-commerce brasileiro 
no período de 2016 a 2019, coletados pela Olist. Através dele foi possível 
observar quais estados possuem maior atraso nos pedidos, se os atrasos 
afetam as avaliações dos produtos e quais categorias de produtos são 
mais e menos bem avaliadas.

## 🛠️ Tecnologias utilizadas
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
